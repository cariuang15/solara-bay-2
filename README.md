# Solara Bay

Game dunia terbuka 2D dari atas (*top-down*) di kota pantai fiktif Solara Bay.
Kamu Leo Marín, anak baru yang bekerja untuk Mama Rosa. Jelajahi kota,
curi mobil, kabur dari polisi, dan selesaikan enam misi cerita — sampai
skor terakhir di Kasino Cahaya.

An open-world 2D top-down crime game in the fictional coastal city of
Solara Bay. You are Leo Marín, working for Mama Rosa. Explore the city,
steal cars, outrun the police, and finish six story missions.

## Cara main / How to play

Buka `game/index.html` di peramban desktop (atau jalankan `node serve.ts`
lalu buka http://localhost:8080).

| Tombol | Aksi |
| --- | --- |
| WASD / Panah | Jalan kaki dan mengemudi |
| E | Masuk / keluar mobil |
| F | Pukul |
| Klik tetikus | Tembak ke arah kursor |
| Shift | Lari |
| P | Jeda |
| H | Bantuan |
| M | Suara hidup/mati |
| L | Simpan permainan |

## Isi game / Features

- Kota terbuka: jalan, trotoar, gedung, taman, pantai, dan dermaga.
- Lalu lintas dan pejalan kaki yang hidup; mobil bisa dicuri.
- Tingkat buron bintang 1–5: polisi mengejar, memasang blokade, dan menangkap.
- Enam misi cerita untuk Mama Rosa: antar paket, kabur dari razia, tarik
  tunai bank, jemput Dani, balapan pantai, dan skor terakhir di kasino.
- Tempur jarak dekat (pukul) dan jarak jauh (tembak), uang tunai tersebar,
  HUD lengkap dengan minimap, layar judul, jeda, bantuan, dan simpanan.
- Suara disintesis (mesin, sirene, tembakan) — tanpa berkas suara.

## Teknologi

Canvas 2D polos, modul ES tanpa pustaka, tanpa build step, tanpa
permintaan jaringan. Semua berkas ada di `game/`.
